# 規格書：移除無意義動態與模板痕跡（視覺清理）

> 狀態：已實作｜ 語彙依據：[CONTEXT.md](../../CONTEXT.md) ｜ 承接：[規格書 0001](0001-f1-paddock.md) 的「視覺系統」

## Problem Statement

使用者在瀏覽網站時遇到幾個「意義不明」的畫面反應，以及一些讓網站看起來像模板產物的裝飾：

- 捲動頁面時，頂端有一條會隨捲動變長、還會換顏色的進度條。使用者看不出它代表什麼。
- 同時，整頁背景有一層會隨捲動區塊悄悄換色的淡色層，使用者同樣無從理解。
- 在賽道詳情頁捲動時，一條白線會沿著賽道「畫」出來。使用者覺得那是一條在賽道上移動的白線，不知道它想說什麼。
- 首頁 hero 有一團紅色放射暈光，捲動時還會以不同速度位移。
- 標題一律全大寫；Logo 與車手照片有彩色光暈；導覽連結是圓角膠囊。這些與全站「銳角、無光暈」的計時螢幕語言不一致，是各類模板共有的預設。

## Solution

保留「圍場計時螢幕」的整體方向（深色分層、列式版面、車隊色條、Titillium Web 字體），只移除上述反應與裝飾：

1. 移除頂端滾動進度條。
2. 移除整頁隨區塊變色的淡色層，整頁底色固定為 `--ground`。
3. 賽道詳情頁直接顯示完整、靜止的賽道線，保留紅色起跑點標記，移除描繪動畫與底層淡色參照線。
4. 移除首頁 hero 的紅色暈光與捲動視差，hero 為平的 `--ground` 底。
5. 英文標題改用原本大小寫；只有首頁 hero 的大賽事名維持全大寫，作為全站唯一的招牌。
6. 移除 Logo 與車手大頭照的彩色光暈；導覽連結改為全站一致的銳角。狀態 pill（如「直播中」）保留圓角。

進場動態不變：首頁倒數板載入時的一次揭示，仍是全站唯一的進場動畫（目前程式已是這樣，本次不動）。

## User Stories

1. 作為訪客，我想捲動頁面時頂端沒有會變長的色條，這樣我不必猜它代表什麼。
2. 作為訪客，我想整頁背景不會隨捲動悄悄換色，這樣畫面穩定、不分散我讀內容的注意力。
3. 作為訪客，我想在積分戰況區看到的色彩只來自車隊色條與數字，這樣顏色只代表「這支車隊」。
4. 作為訪客，我想在賽道詳情頁一打開就看到完整賽道形狀，這樣不必捲動才能看見賽道。
5. 作為訪客，我想賽道線捲動時保持靜止，這樣不會誤以為有東西在賽道上移動。
6. 作為訪客，我想仍能在賽道圖上看到紅色起跑點，這樣知道賽車從哪裡出發。
7. 作為訪客，我想點開賽道放大檢視時看到與頁面上相同的完整賽道線，這樣兩處一致。
8. 作為訪客，我想在賽道列表的縮圖看到與詳情頁相同的線條樣式，這樣辨識一致。
9. 作為訪客，我想首頁 hero 沒有位移的紅色暈光，這樣倒數與賽事名稱是畫面唯一重心。
10. 作為訪客，我想捲動首頁時 hero 內容與頁面其餘部分同速移動，這樣不會有內容滑動不同步的感覺。
11. 作為訪客，我想首頁 hero 的大賽事名仍是全大寫的大字，這樣首頁仍有鮮明的視覺招牌。
12. 作為訪客，我想列表頁與戰況區的標題使用一般大小寫，這樣英文專有名詞（如 McLaren）保持其正式寫法。
13. 作為訪客，我想車隊 Logo 與車手大頭照沒有彩色光暈，這樣車隊色只出現在色條與數字上。
14. 作為訪客，我想導覽連結是與其他元件一致的銳角，這樣整站形狀語言統一。
15. 作為訪客，我想目前頁面的導覽連結仍有紅色底線標示，這樣我知道自己在哪一頁。
16. 作為訪客，我想「直播中」之類的狀態 pill 仍是圓角醒目標籤，這樣狀態一眼可辨。
17. 作為訪客，我想首頁倒數板載入時仍有那一次揭示，這樣首頁仍有一個有意義的進場時刻。
18. 作為開啟「減少動態」的訪客，我想頁面完全不依賴動畫就能呈現所有資訊，這樣體驗沒有差異。
19. 作為手機訪客，我想賽道圖與導覽在窄螢幕上不溢出，這樣清理後版面仍可用。
20. 作為維護者，我想站內不再有只服務單一動畫的程式（進度條元件、區塊色觀察器），這樣程式碼少、不留死碼。
21. 作為維護者，我想設計系統文件如實說明現存動態，這樣未來新增功能者不會依據過時規則決策。

## Implementation Decisions

- 刪除滾動進度條元件及其在應用外殼的掛載與樣式。
- 一併刪除由它驅動的整頁區塊色層：`--section-accent` 變數、背景淡色層偽元素、各區塊的 `data-accent` 屬性與其唯一消費者（積分戰況區、橫向預覽區傳入的代表色）。`data-accent` 若無其他用途則整個移除。
- 賽道平面圖元件只剩單一靜態呈現：移除 `scroll` 模式、`useScroll`／dashoffset 描繪、ghost 參照線與 `static`／`scroll` 的樣式分支。起跑點標記保留，改為任何有外框的賽道圖都顯示（詳情頁與放大檢視需要；列表縮圖是否顯示起跑點維持現狀＝不顯示）。賽道詳情頁以靜態線寬呈現，與放大檢視及縮圖共用同一套線條樣式。
- 首頁：移除 `hero__glow` 元素與樣式、視差的 `useScroll`／`useTransform` 與前景位移；hero 內容容器保持存在以維持版面。
- 全大寫：只保留首頁 hero 的賽事名稱標題；列表頁標題、戰況區標題、其他頁面的 hero 標題與「直播中」大字，移除 `text-transform: uppercase`。實作時需確認「直播中」大字（`hero__live`）是否屬於首頁 hero 招牌；預設視為招牌的一部分，與賽事名一起保留。
- 光暈：移除 Logo 銘牌與車手 hero 大頭照的 `box-shadow` 彩色光暈；邊框用色與車隊色條不動。
- 導覽連結的圓角改用全站 `--radius`；Pill 保留 `999px`（`--radius` 規則的唯一例外）。
- 進場動態（`useEntrance`）維持現狀：只有 `reveal: true`（首頁）才有位移；其餘頁面維持「已在位」變體。不拆除既有 `motion` 包裝元件，避免無關的大範圍 diff。
- 文件：更新 [規格書 0001](0001-f1-paddock.md)「視覺系統」與 styles.css 頂部註解中提到「賽道隨滾動描繪」「滾動進度」「區塊色層」「視差」的段落，使文字與實況一致。是否另立 ADR 由實作者判斷；此變更可逆性高、非驚人決定，預設不需要 ADR。
- 詞彙：不新增 CONTEXT.md 術語（本次無領域概念變化）。

## Testing Decisions

- 好測試只驗外部行為，不驗內部實作。本次多為刪除，大部分以建置與型別檢查把關：`tsc` 與 `vite build` 通過、無殘留的未使用匯入與樣式引用。
- 唯一值得加測試的邏輯：若賽道幾何的投影（外框轉 SVG 路徑與起跑點座標）有變動，沿用現有 `trackGeometry` 的單元測試；本次預期不改該模組，故不新增。
- 驗證接縫（建議單一接縫）：用瀏覽器預覽在首頁、賽道詳情頁、賽道列表、車隊與車手頁各捲動一次，確認沒有進度條、背景不變色、賽道線靜止完整、起跑點仍在；並以「減少動態」模擬確認一致。
- 先例：[設計稽核](../../.scratch)曾以人工預覽驗證視覺變更；專案目前沒有元件／視覺測試，不為此新增。

## Out of Scope

- 更換配色、字體、版型或整體視覺調性。
- 新增任何動畫或視覺特效。
- 拆除其餘頁面既有、已無實際位移的 `motion` 包裝元件。
- 資料、路由、雙語命名或 Profile 的任何變動。

## Further Notes

- 設計稽核的其他結論（近黑底加單一鮮紅屬常見預設、卡片頂端色條等）經討論決定保留，因為它們承載車隊色語意。若日後想讓視覺更鮮明，另開規格。
- 原先提出的「移除各頁交錯淡入」一項，經查程式已是只有首頁有進場位移，故列為「現況維持」而非變更。
