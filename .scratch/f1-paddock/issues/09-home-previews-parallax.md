# 09 — 首頁三區預覽與視差

**What to build:** 首頁下半段依序帶出車隊、車手、賽道三個橫向預覽區，每一區都能滑動瀏覽並通往完整列表。Hero 具備視差，滾動時前景與背景以不同速度移動；區塊背景色隨滾動滲入當前車隊的代表色。

**Blocked by:** 06, 08

**Status:** done

- [x] 車隊／車手／賽道三個橫向預覽區就位，各有「查看全部」入口
- [x] 預覽卡片複用票 04／05／06 既有元件，不另建一套
- [x] Hero 具備視差效果，前景與背景移動速度不同
- [x] 區塊背景色隨滾動漸變至當前車隊代表色
- [x] 窄螢幕**自動關閉視差**，保留淡入與交錯進場
- [x] `prefers-reduced-motion` 開啟時視差與漸變皆停用
- [x] 滾動過程不掉幀，動畫僅使用 transform／opacity
