# 13 — 換季遞延與 Off-season 降級

**What to build:** 跨年時網站自行呈現新球季，無需任何人介入。新球季尚未開賽的那兩個多月，積分區塊顯示上一季的最終結果並明確標示年份，賽程與倒數則指向新球季。本季結束後的 Off-season，Hero 改為倒數至下季開幕。

依 ADR-0004——**這些情境在真實世界一年只發生一次，全部以注入的模擬時間驗證**。

**Blocked by:** 09, 10

**Status:** ready-for-agent

- [ ] 程式中無任何寫死的年份
- [ ] 模擬時間跨年時，賽程與倒數自動指向新球季
- [ ] 新球季無 standings 時，積分區塊回退為上一季最終結果**並明確標示年份**
- [ ] 新球季首站結束後自動切回即時資料
- [ ] Off-season 時 Hero 倒數指向下一季開幕，而非顯示空白或負數
- [ ] 以上全部由注入模擬時間的測試涵蓋，不依賴真實系統時鐘
